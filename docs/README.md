# 文档索引

本目录是客户端后续开发的参考文档。所有结论都以**当前代码**为准；若文档与代码冲突，改文档，不要改代码去迎合文档。

| 文档 | 解决什么问题 | 什么时候读 |
| --- | --- | --- |
| [`../AGENTS.md`](../AGENTS.md) | 不可越界的原则、技术基线、文件地图、关键不变量、验证命令、提交前清单 | 第一次接手、或在动手改任何代码之前 |
| [`architecture.md`](architecture.md) | 分层职责、启动认证恢复/列表/打开聊天/首屏/轮询/发送/删除的数据流、关键状态机与分层取舍 | 要新增功能、排查状态错乱、判断一段逻辑应该放在哪一层时 |
| [`protocol.md`](protocol.md) | 客户端实际依赖的 Oxype HTTP 契约：认证方式、信封形状、错误分类、每个端点的请求/响应要点、消息结构与头像规则 | 对接服务器、协议报错、服务端字段变化、要改 `data/oxype` 层时 |
| [`development.md`](development.md) | JDK/SDK 环境、构建/测试/lint/安装命令、MuMu 模拟器与 fixture 联调、logcat、常见故障排查 | 搭环境、跑构建、联调 UI、遇到"连不上/构建失败"时 |

相关但不是本目录维护的：

- 仓库根 `README.md`：面向项目使用者的概览（功能范围、默认服务器、构建命令）。不要在本目录重复它。
- `tools/ui-fixture/README.md`：本机协议模拟器的路由与账号说明。
